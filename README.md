# bitwise

AI-generated Brilliant-style content.

## Purpose

`bitwise` produces interactive, bite-sized learning content in the spirit of
Brilliant — concept-driven lessons that teach through active problem solving
rather than passive reading, generated with AI.

- **Brilliant-style lessons** — short, focused modules that build intuition
  step by step.
- **AI generated** — content (explanations, problems, hints, solutions) is
  produced by language models.
- **Interactive** — emphasis on doing: quizzes, guided problems, and immediate
  feedback.

## Goals

- Scale high-quality interactive lessons through generation.
- Cover topics across STEM in an engaging, hands-on format.

## Status

Early / scaffolding. This directory currently holds only project intent.
